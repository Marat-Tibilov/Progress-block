# Progress

Круговой индикатор на чистом HTML, CSS и JS.

**Демо:** https://marat-tibilov.github.io/Progress-block/

## Запуск

Открыть `index.html` двойным кликом не получится — страница останется пустой.
`main.js` подключён как ES-модуль, а модули не загружаются со схемы `file://`.
Нужен любой локальный HTTP-сервер: встроенный в редактор, расширение для браузера
или статический сервер из консоли.

Если нужно именно открытие файлом, без сервера, то нужно отказаться от модулей:

- в `index.html` заменить `<script type="module" src="main.js">` на два тега
  `<script defer src="progress.js">` и `<script defer src="main.js">`
- в `progress.js` убрать `export` у класса, в `main.js` — строку `import`.

`Progress` станет глобальным — тогда страница откроется и с `file://`.
